# woodjme/homebrew-tap

Homebrew formulae for tools by [woodjme](https://github.com/woodjme).

```sh
brew install woodjme/tap/<formula>
```

| Formula | Description |
|---|---|
| [secretary](https://github.com/woodjme/secretary) | Terminal UI for AWS Secrets Manager |

Formulae are updated automatically when a project publishes a release.
